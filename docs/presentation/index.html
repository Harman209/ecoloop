the problem

the linear packaging trap

why conventional municipal recycling breaks down on complex packaging

material reality linear
  • multi-layer packaging (mlp)
    chips and snack wrappers bond plastic and aluminum together. recyclers cannot separate them profitably, so they go directly to landfills.
  • zero supply tracking
    schools and communities generate tons of clean packaging waste without verified channels to divert materials into local production loops.
the ecoloop objective circular
  • direct mechanical upcycling
    heat-press multi-layer plastics into structural sheets that replace plywood and acoustic boards.
  • digital transparency
    publish physical specifications, density metrics, and inventory through an open platform.

the engine

the closed-feedback agentic loop

it is not copy-pasting answers; it is an automated engineering cycle

1. specification rules

define boundaries in AGENTS.md: design tokens, allowed libraries, performance budgets, and file structures.

2. autonomous edit agent

the agent inspects the repository, plans file changes, and modifies code across multiple files simultaneously.

3. compiler verification truth

automated execution of tsc and vite build. if errors occur, the agent reads terminal output and repairs itself.

4. git checkpoint persistence

atomic git commits at each verified step guarantee a clean recovery path if an experiment fails.

why opencode?
  • 100% open source

    plan mode surveys codebase structure without editing; build mode executes verified changes.

    integrates with git, bash tools, local linters, and compilers out of the box.
